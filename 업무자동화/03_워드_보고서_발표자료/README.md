# 업무 자동화 3편 — 워드 보고서로 발표 PPT 만들기, 한 문장으로 고치기

워드 영업 보고서 한 개로 클로드에게 발표용 PPT 를 만들게 하고, **같은 대화에서 한 문장을 더 보내** 고친 예제입니다.

- 처음 — `부탁1_처음_한줄.txt` 한 줄만 보냄 → `결과1_한줄로_처음_받은_PPT.pptx`
- 이어서 — 같은 대화에 `부탁2_이어서_고치기.txt` 를 보냄 → `결과2_한문장으로_고친_PPT.pptx`

가이드(설명 · 실측 결과 · 부탁 문장 전문): https://www.coding-now.com/guides/word-report-to-ppt

## 파일

| 파일 | 내용 |
|---|---|
| `예제_2026년_3분기_영업보고서.docx` | 가상 회사 「예시문구」 2026년 3분기 영업 보고서(연습용 가짜 자료) — 한눈에 보기 · 지점별 · 월별 · 품목별 표 3개 · 잘된 점 · 아쉬운 점 · 4분기 계획 · 회사 색 |
| `부탁1_처음_한줄.txt` | 처음 보낸 문장 그대로(UTF-8) |
| `부탁2_이어서_고치기.txt` | 같은 대화에 이어서 보낸 문장 그대로(UTF-8) |
| `결과1_한줄로_처음_받은_PPT.pptx` | 클로드(Claude 데스크톱 앱 Code 탭)가 첫 문장으로 만든 PPT 그대로 — 10장 |
| `결과2_한문장으로_고친_PPT.pptx` | 같은 대화에서 두 번째 문장으로 고친 PPT 그대로 — 10장(첫 파일은 그대로 두고 새 파일로 저장됨) |
| `measure.py` | 아래 숫자를 잰 스크립트(python-pptx · 파워포인트를 띄우지 않고 파일만 읽음) |
| `measure.json` | 위 스크립트의 결과 |

PPT 두 개의 작성자 · 마지막 수정한 사람은 CODINGNOW 로 바꿨고, 장 · 글 · 그래프는 클로드가 만든 그대로입니다.

## 고치기 전 · 뒤 (2026-11-26)

| 항목 | 처음 받은 PPT | 한 문장으로 고친 PPT |
|---|---|---|
| 장 수 | 10 | 10 |
| 걸린 시간(앱에 보인 시간) | 10분 59초 | 7분 15초 |
| 장마다 글자 가운데 값 — 영상 판정표 기준 | 127.5자 | 36.5자 |
| 장마다 글자 가운데 값 — `measure.py` 기준 | 120.5자 | 35자 |
| 표 | 2개 | 0개 |
| 그래프 | 5개 | 10개 |
| 보고서에 없는 숫자(글 · 표 · 그래프 값 · 발표자 노트) | 0개 | 0개 |
| 발표자 노트 있는 장 | 10/10 | 10/10 |
| 칸 밖으로 넘친 글 | 0 | 0 |

- 글자 수는 빈칸 · 그래프 이름표 · 제목을 빼고 셉니다. 영상 판정표와 `measure.py` 는 쪽 머리(「01 한눈에 보기」 같은 작은 이름표)를 세는 방법이 달라 숫자가 조금 다릅니다 — 줄어든 방향과 크기는 같습니다.
- 「보고서에 없는 숫자」는 쪽 머리의 차례 번호(01~08)를 빼고 셉니다.
- 칸 밖으로 넘친 글은 영상 쪽에서 파워포인트를 창 없이 열어 글 높이 · 위치를 재고, 의심 가는 곳(전 · 뒤 각 1곳)은 그림을 확대해 상자 안인 것을 확인했습니다.
- 처음부터 두 번째 문장의 조건을 붙여 따로 3번 돌렸을 때: 장마다 글자 가운데 값 50자 · 걸린 시간 가운데 값 14분 40초.
- AI 결과는 다시 돌리면 달라질 수 있습니다. 위 숫자는 영상 녹화 때 한 번 돌린 결과입니다(사람이 고친 곳 없음).
