# 업무 자동화 1편 — 엑셀 파일 24개 한 장으로 합치기

지점마다 모양이 다른 월 매출 엑셀 24개를 **한 표로 합치는** 예제입니다. 같은 파일로 두 가지 방법을 해 봅니다.

- 엑셀만으로 — 파워 쿼리 '폴더에서'(고친 쿼리 M 코드는 가이드에 전문)
- 클로드에게 시키기 — 아래 `요청문장.txt` 를 그대로 넣기

가이드(설명 · 실측 결과): https://www.coding-now.com/guides/combine-excel-files

## 파일

| 파일 | 내용 |
|---|---|
| `예제_지점별_매출_24개.zip` | 풀면 `input/` 폴더에 엑셀 24개(가상 회사 「예시문구」 6지점 × 2026년 7~10월, 연습용 가짜 데이터) |
| `요청문장.txt` | 클로드에게 넣은 요청 문장 그대로(UTF-8) |
| `검산_지점월별_정답.csv` | 지점 × 월 금액 합계 정답(총 43,665,600원) — 합친 결과를 이것과 맞춰 봅니다 |
| `pq_measure.py` | 숨긴 엑셀에서 파워 쿼리 세 가지를 돌려 줄 수 · 합계를 재는 스크립트(Windows + 엑셀 · pywin32 · pymupdf · pillow) |
| `pq_measure.json` | 위 스크립트의 결과 |

## 그냥 이어 붙이면 틀리는 곳

| 지점 | 파일 이름 예 | 함정 |
|---|---|---|
| 서울 | `서울_7월_매출.xlsx` | 제목 · 빈 줄 아래 3행이 머리글 |
| 부산 | `부산지점 2026-07 매출보고.xlsx` | 머리글이 `품목명 · 단가 · 판매수량 · 매출액`(이름 · 순서가 다름) · 맨 아래가 **'총계'** |
| 대구 | `대구 07월.xlsx` | 제목 3줄 아래 4행이 머리글 · '비고' 열 · 「부가세 포함」 표기 |
| 인천 | `인천(7월)매출.xlsx` | 숫자가 모두 글자(`'20,800'`) — SUM 하면 0 |
| 광주 | `2026년7월_광주.xlsx` | 첫 시트가 '메모', 자료는 둘째 시트 '매출' |
| 대전 | `대전_판매기록_7월.xlsx` | 하루 기록(판매일 열) · 합계 줄 없음 |
