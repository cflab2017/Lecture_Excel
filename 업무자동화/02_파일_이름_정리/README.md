# 업무 자동화 2편 — 파일 이름 30개 한꺼번에 정리

이름이 제각각인 회의록 · 보고서 30개를 **「2026-10-06_주간회의.docx」처럼 날짜_제목** 으로 바꾸는 예제입니다. 같은 파일로 두 가지 방법을 해 봅니다.

- 직접 — PowerShell 로 파일 목록 CSV 를 만들고, 엑셀에서 새 이름을 적어 **「CSV UTF-8」** 로 저장한 뒤 PowerShell 한 줄로 바꾸기
- 클로드에게 시키기 — 아래 `요청문장.txt` 를 그대로 넣기

가이드(설명 · 실측 결과 · 명령 전문): https://www.coding-now.com/guides/rename-files

## 이름만 보고 바꾸면 틀리는 곳

| 함정 | 예제에서 |
|---|---|
| 파일 수정 시각 ≠ 문서 날짜 | 수정 시각으로 날짜를 정하면 날짜가 있는 29개 중 **1개** 만 맞음 |
| 이름에 날짜가 없음 | 5개(`회의록 (1)` · `회의록_진짜최종` · `주간회의` · `주간보고 최신` · `주간보고(10월 넷째주)`) — 문서 안 「일시」 · 「작성일」 줄을 봐야 함 |
| 연도가 없음 | 월 · 일만 있는 이름 18개(`0915` · `10.27` · `9-29` · `9월22일` …) |
| 이름 꼬리 ≠ 판 순서 | `주간회의 11월 3일 수정본` 은 고친 줄 0개, `회의록 (1)` 은 1개 — 같은 날 여러 판 7묶음은 문서 안 「■ 고친 것」 줄 수로 순서를 정함 |
| 사본 · 빈 파일 · 대문자 확장자 | `회의록 2026.9.8 - 복사본` 은 원본과 내용 해시까지 같음 · `새 텍스트 문서.txt` 는 0바이트 · `.DOCX` |
