# 기초 4강 — 엑셀 자동 채우기 · 행 추가 (채우기 핸들, 평일만 채우기, 끼운 행이 합계에서 빠질 때)

- 강의: https://www.coding-now.com/blog/excel/excel-basic-04-autofill-insert-row
- English: https://www.coding-now.com/en/blog/excel/excel-basic-04-autofill-insert-row

## 파일

| 파일 | 내용 |
|---|---|
| `실습.xlsx` | 따라 할 파일 — 가상 학원 수업표(번호 · 날짜 · 요일 · 주차 · 과목 · 수강생 10줄 + 합계), 번호·날짜·요일·주차는 첫 줄만 |
| `정답.xlsx` | 채운 수업표 + 합계 바로 위에 새 수업 한 줄 + 합계 =SUM(F2:F12)(140) |
| `practice.xlsx` · `answer.xlsx` | 영어판 강의용 같은 연습 파일(영어 머리글·과목 이름, 수강생 수는 같음) |
| `measure.py` → `measure.json` | 강의에 적은 값을 엑셀로 다시 재는 스크립트 — Range.AutoFill 형식별(기본·연속·평일·월) 결과, Ctrl+D(FillDown), 합계 위·범위 안·세 줄 행 삽입 뒤 합계 수식·값·오류 표시, 평일 날짜와 따로 끈 요일, =TEXT(B2,"aaa") |
| `measure.py en` → `measure_en.json` | 영어판 자료로 같은 측정 + 영어판 연습 파일 |
| `measure_util.py` | 수업표 채우기·창 찍기 공통 |
| `screens.py` · `series_dialog.py` → `crop_web.py` | 강의 화면(`shots/`, 저장소에는 올리지 않음)과 '연속 데이터' 창을 찍어 강의 페이지용으로 자른 스크립트 |

스크립트는 Windows + 엑셀 + `pip install pywin32 pillow` 에서 돈다. 엑셀을 따로 띄워 쓰고, 시험 통합 문서는 저장하지 않고 닫는다.

## 핵심

- 채우기 핸들(고른 칸 오른쪽 아래 작은 네모)을 끌면: 1 한 칸 → 1 복사, 1·2 → 1~10, 2·4 → 2·4·6…, 날짜 → 하루씩(토·일 포함), '월' → 화·수…, '1주차'·'1반'·'1월' → 숫자만 하나씩, '수학' → 복사, =A1*2 → =A2*2…, =A1*$B$1 → $B$1 그대로.
- Ctrl+D(홈 → 채우기 → 아래쪽) = 맨 위 칸을 아래로 복사 — =A1+1 → =A2+1 · =A3+1.
- 평일만: 홈 → 채우기 → 계열… → '연속 데이터' 창 → 날짜 단위 평일 — 11-06(금) 다음 11-09(월). 월 단위 → 11-06 · 12-06 · 2027-01-06….
- 날짜를 평일로 다시 채워도 따로 끈 요일 칸은 그대로(11-09 옆 '토') → =TEXT(B2,"aaa")(영어판 "ddd")로 날짜에서 읽으면 늘 맞음. '1주차' 를 끌면 줄마다 하나씩(1~10주차).
- 합계(=SUM(F2:F11)) 바로 위 12행에 행을 끼우고 20명을 넣어도 합계 120(넣으면 140), 오류 표시 '인접한 셀 생략'(Errors(5)) 켜짐. 마지막 데이터 줄(11행) 위에 끼우면 =SUM(F2:F12) 로 늘어 140.
- 5:7 세 줄을 한 번에 삽입 → 번호 1·2·3·(빈칸 셋)·4…, 합계는 =SUM(F2:F14) 로 늘어남. 1·2 를 골라 다시 끌면 1~13.
