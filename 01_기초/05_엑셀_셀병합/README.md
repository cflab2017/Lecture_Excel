# 기초 5강 — 엑셀 셀 병합 (병합하고 가운데 맞춤, 정렬 오류 · 필터에 한 줄만 나올 때, 병합 없이 가운데)

- 강의: https://www.coding-now.com/blog/excel/excel-basic-05-merge-cells
- English: https://www.coding-now.com/en/blog/excel/excel-basic-05-merge-cells

## 파일

| 파일 | 내용 |
|---|---|
| `실습.xlsx` | 따라 할 파일 — 가상 점수표(반 · 이름 · 점수 6명), 제목 A1:C1 과 반(A3:A5 · A6:A8)이 병합돼 있음 |
| `정답.xlsx` | 반 병합 해제 → 빈칸을 위 칸 값으로 채움 → 점수 내림차순 정렬 · 필터, 제목은 '선택 영역의 가운데로'(병합 아님) |
| `practice.xlsx` · `answer.xlsx` | 영어판 강의용 같은 연습 파일 |
| `measure.py` → `measure.json` | 강의에 적은 값을 엑셀로 다시 재는 스크립트 — 병합 전후 · 해제 뒤 값, 전체 병합, 병합 섞인 표 정렬 오류 문구, '1반' 필터 보이는 줄, 해제 뒤 빈 셀 채우기 · 필터 · 정렬, 선택 영역의 가운데로, 메뉴 글자 |
| `measure.py en` → `measure_en.json` | 영어판 자료로 같은 측정 |
| `make_files.py` | 실습 · 정답 파일 만들기(`en` 이면 영어판) |
| `screens.py` · `goto_special.py` → `crop_web.py` | 강의 화면(`shots/`, 저장소에는 올리지 않음) — 병합 경고 · 정렬 오류 창(알림을 켜야 뜸) · 필터 · 셀 서식 맞춤 · 이동 옵션 |

스크립트는 Windows + 엑셀 + `pip install pywin32 pillow` 에서 돈다. 엑셀을 따로 띄워 쓰고, 시험 통합 문서는 저장하지 않고 닫는다.

## 핵심

- 값이 든 A1 · B1 · C1 을 병합 → '셀을 병합하면 왼쪽 위의 값만 남고 나머지 값은 잃게 됩니다.' → A1 값만 남음, 병합을 풀어도(셀 분할) B1 · C1 빈칸.
- 전체 병합(Merge(True)): E1:G2 → E1:G1 · E2:G2 줄마다.
- 반을 세 줄씩 병합한 표를 점수로 정렬 → '이 작업을 수행하려면 병합하려는 모든 셀의 크기가 동일해야 합니다.'(표 그대로). DisplayAlerts 를 끄면 오류 창도 없이 정렬만 안 됨.
- 같은 표 '1반' 필터 → 6개 중 1개(김민준만). 병합 값은 첫 칸에만.
- 병합 해제 → 빈 셀 4개(SpecialCells 빈 셀 = 이동 옵션 → 빈 셀) → =위 칸 → 필터 3명 · 정렬 됨(95 · 91 · 88 · 82 · 77 · 70).
- 선택 영역의 가운데로(HorizontalAlignment 7): 병합 아님, B1 빈칸 그대로, 정렬 됨.
