# 기초 2강 — 엑셀 표 만들기 (테두리로 그리는 표와 표 서식 Ctrl+T)

- 강의: https://www.coding-now.com/blog/excel/excel-basic-02-table
- English: https://www.coding-now.com/en/blog/excel/excel-basic-02-table

## 파일

| 파일 | 내용 |
|---|---|
| `실습.xlsx` | 따라 할 파일 — 꽃집 주문 8건(금액 열은 비어 있음), 데이터는 모두 가상 |
| `정답.xlsx` | 표 서식(이름 '주문표') + 계산 열 `=[@수량]*[@단가]` + 요약 행 610,000 |
| `practice.xlsx` · `answer.xlsx` | 영어판 강의용 같은 연습 파일(달러, 요약 행 $610) |
| `measure.py` → `measure.json` | 강의에 적은 값을 엑셀로 다시 재는 스크립트(테두리 표의 새 줄·SUM, 한 열만 정렬, 빈 줄, 표 서식의 계산 열·자동 확장·요약 행·필터·정렬, 머리글 이름, 병합, 범위로 변환) |
| `measure_en.py` → `measure_en.json` | 영어판 자료로 같은 측정 + 영어판 연습 파일 |
| `measure_util.py` | 데이터·시트 채우기·창 찍기 공통 |
| `screens.py` → `crop_web.py` | 강의 화면을 찍고(`shots/`, 저장소에는 올리지 않음) 강의 페이지용으로 자른 스크립트 |

스크립트는 Windows + 엑셀 + `pip install pywin32 pillow` 에서 돈다. 엑셀을 따로 띄워 쓰고, 시험 통합 문서는 저장하지 않고 닫는다.

## 핵심

- 테두리 표(홈 → 글꼴 → 테두리 → 모든 테두리)는 선만 그린다 — 바로 아래 새 줄은 테두리도 없고 `=SUM(F2:F9)` 에도 안 들어간다(610,000 그대로).
- 표 서식(Ctrl+T)은 새 줄까지 표가 늘고(A1:F9 → A1:F10), 한 칸에 넣은 `=[@수량]*[@단가]` 가 열 전체에 채워진다.
- 요약 행 = `=SUBTOTAL(109,[금액])` — 필터로 '장미 꽃다발'만 보이면 210,000, 표 밖 SUM 은 740,000.
- 한 열만 골라 정렬하고 '현재 선택 영역으로 정렬'을 고르면 8줄 중 7줄의 상품이 바뀐다(오류 표시 없음).
