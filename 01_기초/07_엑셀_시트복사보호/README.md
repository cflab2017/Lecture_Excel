# 기초 7강 — 엑셀 시트 복사 · 시트 보호 (다른 파일로 복사하면 생기는 외부 연결, 일부 칸만 입력되게 잠그기)

- 강의: https://www.coding-now.com/blog/excel/excel-basic-07-copy-protect-sheet
- English: https://www.coding-now.com/en/blog/excel/excel-basic-07-copy-protect-sheet

## 파일

| 파일 | 내용 |
|---|---|
| `실습.xlsx` | 따라 할 파일 — 가상 독서 모임 11월 회비. '11월' 시트의 낸 금액 =IF(B3="O",설정!$B$1,0) 이 '설정' 시트의 월 회비(10,000)를 읽음. 보호 없음 |
| `정답.xlsx` | 11월을 복사한 12월 시트(납부 여부 비움), 두 시트 모두 납부 여부(B3:B8)만 잠금 해제 · 낸 금액(C3:C9) 수식 숨김 · 시트 보호(암호 없음) |
| `practice.xlsx` · `answer.xlsx` | 영어판 강의용 같은 연습 파일(Nov · Dec · Settings) |
| `measure.py` → `measure.json` | 강의에 적은 값을 엑셀로 다시 재는 스크립트 — 같은 파일 안 복사 · 새 통합 문서로 복사(외부 연결) · 설정 시트와 같이 복사 · 범위 복사 열 너비 · 시트 보호 · 잠금 해제 칸 · 수식 숨김 · 보호된 시트 복사 · 삭제 · 이름 바꾸기 · 통합 문서 구조 보호 · 암호 |
| `measure.py en` → `measure_en.json` | 영어판 자료로 같은 측정 |
| `make_files.py` | 실습 · 정답 파일 만들기(`en` 이면 영어판) |
| `screens.py` → `screens.json` · `crop_web.py` | 강의 화면(`shots/`, 저장소에는 올리지 않음) — 이동/복사 창 · 복사 뒤 시트 탭 · 새 통합 문서의 외부 연결 수식 · 셀 서식 보호 탭 · 시트 보호 창 |

스크립트는 Windows + 엑셀 + `pip install pywin32 pillow` 에서 돈다. 엑셀을 따로 띄워 쓰고, 시험 통합 문서는 %TEMP% 에 저장했다가 저장하지 않고 닫는다.
pywin32 늦은 바인딩에서는 `ws.Copy(After=ws)` 같은 이름 붙인 인자가 무시돼 새 통합 문서로 복사된다 — `ws.Copy(None, ws)` 처럼 자리로 넘긴다.
암호를 건 시트에 암호 없이 `Unprotect()` 를 부르면 엑셀이 암호 입력 창을 띄워 멈추므로 그 경우는 재지 않았다.

## 핵심

- 같은 파일 안 복사(이동/복사 → 복사본 만들기): 새 시트 '11월 (2)', 수식 · 합계(40,000) · 열 너비(12 · 10 · 12 · 22) 그대로.
- 11월 시트 하나만 새 통합 문서로: C3 =IF(B3="O",[회비장부.xlsx]설정!$B$1,0) — 외부 연결(LinkSources 에 원본). 실습 파일로 하면 [실습.xlsx].
- 11월 + 설정 두 시트를 같이 새 통합 문서로: C3 =IF(B3="O",설정!$B$1,0), 외부 연결 없음.
- 범위(A1:D9)만 복사해 붙여넣기: 열 너비 모두 8.38(기본).
- 모든 칸 기본 잠금. 시트 보호(암호 없음) → 입력 막힘('변경하려는 셀 또는 차트가 보호된 시트에 있습니다…'), 셀 서식 · 행 삽입 · 정렬 허용 꺼짐, 암호 없이 바로 해제됨.
- B3:B8 잠금 해제 + 보호: B5 에 O → 합계 50,000, C3 · A3 막힘, 숨김 켠 C3 은 수식이 자동화로도 읽히지 않음(값 10,000 은 보임).
- 보호된 시트 복사본도 보호된 채. 보호된 시트 이름 바꾸기 · 삭제는 됨 → 통합 문서 구조 보호를 켜면 삭제 · 이름 바꾸기 · 새 시트 · 복사 모두 막힘('통합 문서가 보호되어 있어서 변경할 수 없습니다.').
- 암호 1234 로 보호 → 0000 으로 풀기 막힘('암호가 잘못되었습니다…'), 1234 로 풀림.
