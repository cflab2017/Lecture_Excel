# 기초 3강 — 엑셀 틀 고정 (첫 행 · 첫 열 · 고른 칸 기준, 안 될 때)

- 강의: https://www.coding-now.com/blog/excel/excel-basic-03-freeze-panes
- English: https://www.coding-now.com/en/blog/excel/excel-basic-03-freeze-panes

## 파일

| 파일 | 내용 |
|---|---|
| `실습.xlsx` | 따라 할 파일 — 가상 문구점 품목 60개의 1~12월 판매 수량(A~O열, 틀 고정 없음) |
| `정답.xlsx` | C2 틀 고정(1행 + A:B) + 인쇄 제목(반복할 행 $1:$1 · 반복할 열 $A:$B) |
| `practice.xlsx` · `answer.xlsx` | 영어판 강의용 같은 연습 파일(영어 머리글·품목 이름, 수량은 같음) |
| `measure.py` → `measure.json` | 강의에 적은 값을 엑셀로 다시 재는 스크립트(첫 행·첫 열·C2·A3·C1·B2 틀 고정, 내린 채 고정, A1 고정, 페이지 나누기 미리 보기·페이지 레이아웃 보기, PDF 인쇄 — 틀 고정만 / 인쇄 제목 행 / 행+열) |
| `measure.py en` → `measure_en.json` | 영어판 자료로 같은 측정 + 영어판 연습 파일 |
| `measure_util.py` | 데이터(씨앗 20261106)·시트 채우기·창 찍기 공통 |
| `screens.py` → `crop_web.py` | 강의 화면을 찍고(`shots/`, 저장소에는 올리지 않음) 강의 페이지용으로 자른 스크립트 |

스크립트는 Windows + 엑셀 + `pip install pywin32 pillow pymupdf` 에서 돈다. 엑셀을 따로 띄워(창이 있어야 틀 고정이 된다) 쓰고, 시험 통합 문서는 저장하지 않고 닫는다.

## 핵심

- 보기 → 틀 고정 → 틀 고정 / 첫 행 고정 / 첫 열 고정. 틀 고정은 고른 칸의 위쪽 행 · 왼쪽 열을 고정한다(C2 = 1행 + A:B, B2 = 1행 + A, A3 = 1~2행, C1 = A:B).
- 화면을 15행까지 내린 채 C20 에서 틀 고정 → 15~19행이 고정되고 1~14행(머리글)은 올려도 안 보인다.
- A1 에서 틀 고정 → 화면 가운데(이 창에서는 9행 아래 · I열 오른쪽)에 선.
- 고정된 창에서 같은 '틀 고정' 명령을 다시 실행하면 고정이 풀린다(메뉴 이름은 '틀 고정 취소').
- 페이지 레이아웃 보기로 바꾸면 틀 고정이 풀리고 단추 셋이 회색 — 기본 보기로 돌아와도 꺼진 채. 페이지 나누기 미리 보기에서는 그대로.
- 틀 고정은 인쇄되지 않는다(PDF 2쪽이 '43 스테이플러(파랑)'부터). 인쇄 제목 반복할 행 $1:$1 → 모든 쪽에 머리글, 표가 옆으로도 나뉘면 반복할 열 $A:$B 까지.
