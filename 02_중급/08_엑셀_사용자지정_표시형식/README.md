# 중급 8강 — 엑셀 사용자 지정 표시 형식 (컴활 2급 실기 기본작업 유형 연습)

## 파일

| 파일 | 내용 |
|---|---|
| `실습.xlsx` | `문제` 시트(문제 문장 3개) + `기본작업` 시트([표22]~[표24], 답 범위는 처음 형식 그대로) |
| `정답.xlsx` | 같은 파일의 답 범위에 사용자 지정 표시 형식을 넣은 것 |

엑셀은 따로 띄워 **숨긴 채** 쓴다(창 · 키 입력 · 클립보드 · 화면 캡처 안 씀). 그래서 셀 서식 대화 상자 화면은 없다. 확인 환경: 엑셀 Microsoft 365(버전 16.0), 2026-11-20.

## 문제

**22. (기본)** [표22]에서 나이[B3:B10]는 숫자 뒤에 '세'를 붙여 '34세'처럼, 회비[C3:C10]는 천 단위 구분 기호와 '원'을 붙여 '30,000원'처럼 표시하시오. (회비가 0 이면 '0원'으로 표시) ▶ 셀 서식(Ctrl+1)의 사용자 지정 표시 형식 사용

**23. (응용)** [표23]에서 날짜[B14:B21]는 '2026-12-18(금)'처럼 연-월-일 뒤 괄호 안에 요일을, 예산[C14:C21]은 천 원 단위로 줄여 '1,250천원'처럼 표시하시오. ▶ 사용자 지정 표시 형식 사용(요일은 aaa)

**24. (함정)** [표24]에서 지점[A25:A32]은 이름 뒤에 '점'을 붙여 '서울점'처럼, 전월 대비[C25:C32]는 양수는 '1,120'처럼, 음수는 빨강으로 '-450'처럼, 0 은 '-'로 표시하시오. ▶ 사용자 지정 표시 형식 사용(양수;음수;0 구역)

## 풀이 · 실측 값

범위를 고르고 Ctrl+1 → 표시 형식 → 사용자 지정 → 형식 칸에 아래 코드 → 확인.

| 문제 | 범위 | 형식 코드 | 보이는 값 |
|---|---|---|---|
| 22 | B3:B10 | `0"세"` | 34세 · 28세 · 41세 · 37세 · 26세 · 45세 · 30세 · 52세 |
| 22 | C3:C10 | `#,##0"원"` | 30,000원 · 30,000원 · 0원 · 45,000원 · 30,000원 · 0원 · 45,000원 · 30,000원 |
| 23 | B14:B21 | `yyyy-mm-dd(aaa)` | 2026-12-18(금) · 2026-12-04(금) · 2026-12-12(토) · 2027-01-08(금) · 2027-01-22(금) · 2027-02-20(토) · 2027-02-26(금) · 2027-03-05(금) |
| 23 | C14:C21 | `#,##0,"천원"` | 1,250천원 · 860천원 · 320천원 · 2,480천원 · 540천원 · 1,976천원 · 1,235천원 · 698천원 |
| 24 | A25:A32 | `@"점"` | 서울점 · 부산점 · 대구점 · 인천점 · 광주점 · 대전점 · 울산점 · 수원점 |
| 24 | C25:C32 | `#,##0;[빨강]-#,##0;"-"` | 1,120 · -450 · - · 305 · -1,080 · - · -15 · 2,100 (빨강: C26, C29, C31) |

칸에 든 값은 형식을 넣기 전과 같다(모든 칸 Value2 비교). 확인 칸 E3 =AVERAGE(B3:B10) 36.6 · E14 =SUM(C14:C21) 9,358,460.

## 자주 틀리는 형식 — 같은 범위에 넣어 본 결과

| 범위 | 넣은 것 | 결과(실측) | 왜 |
|---|---|---|---|
| B3:B10 | 글자로 직접 입력(34세 · 28세 …) | 34세 · 28세 · 41세 · 37세 · 26세 · 45세 · 30세 · 52세 · E3 #DIV/0! | 형식 대신 '34세'를 글자로 직접 입력 — 보이는 값은 같지만 숫자가 아님 |
| C3:C10 | `#,###"원"` | 30,000원 · 30,000원 · 원 · 45,000원 · 30,000원 · 원 · 45,000원 · 30,000원 | 0 자리에 # — 값이 0 이면 숫자가 안 보임 |
| B14:B21 | `yyyy-mm-dd(ddd)` | 2026-12-18(Fri) · 2026-12-04(Fri) · 2026-12-12(Sat) · 2027-01-08(Fri) · 2027-01-22(Fri) · 2027-02-20(Sat) · 2027-02-26(Fri) · 2027-03-05(Fri) | 요일을 ddd 로 — 영어 요일 |
| B14:B21 | `yyyy-mm-dd(aaaa)` | 2026-12-18(금요일) · 2026-12-04(금요일) · 2026-12-12(토요일) · 2027-01-08(금요일) · 2027-01-22(금요일) · 2027-02-20(토요일) · 2027-02-26(금요일) · 2027-03-05(금요일) | 요일을 aaaa 로 — '금요일'까지 |
| C14:C21 | `#,##0"천원"` | 1,250,000천원 · 860,000천원 · 320,000천원 · 2,480,000천원 · 540,000천원 · 1,975,500천원 · 1,234,560천원 · 698,400천원 | 끝 쉼표를 빼먹음 — 줄지 않고 '천원'만 붙음 |
| C14:C21 | `#,##0,,"천원"` | 1천원 · 1천원 · 0천원 · 2천원 · 1천원 · 2천원 · 1천원 · 1천원 | 쉼표 둘 — 백만 단위로 줄어듦 |
| A25:A32 | `0"점"` | 서울 · 부산 · 대구 · 인천 · 광주 · 대전 · 울산 · 수원 | 글자 칸에 숫자 형식(0) — 글자에는 안 붙음 |
| C25:C32 | `[빨강]-#,##0;#,##0;"-"` | -1,120 · 450 · - · -305 · 1,080 · - · 15 · -2,100 | 구역 순서를 바꿈 — 첫 구역은 양수 |
| C25:C32 | `#,##0;[빨강]-#,##0` | 1,120 · -450 · 0 · 305 · -1,080 · 0 · -15 · 2,100 | 0 구역을 빼먹음 — 0 이 0 으로 |
| C25:C32 | `#,##0;[빨강]#,##0;"-"` | 1,120 · 450 · - · 305 · 1,080 · - · 15 · 2,100 | 음수 구역에 - 를 안 붙임 — 빨강만, 부호 없음 |
| C25:C32 | `#,##0;[Red]-#,##0;"-"` | 넣지 못함(형식을 받지 않음) | 한국어 엑셀 형식 칸에 영어 [Red] |

## 한 칸 사실(빈 칸에 형식을 넣고 값 · 식)

| 형식 | 값 · 식 | 보이는 값 | 뜻 |
|---|---|---|---|
| `#,##0,"천원"` | 1975500 | 1,976천원 | 천 단위로 줄이면 반올림해서 보임 |
| `#,##0,"천원"` | =SUM(C14:C21) | 9,358천원 | 예산 합계를 천원으로(실제 값으로 더함) |
| `#,##0,,` | 1234567 | 1 | 쉼표 둘 = 백만 단위 |
| `aaa` | 46374 | 금 | aaa = 요일 한 글자 |
| `aaaa` | 46374 | 금요일 | aaaa = 요일 전체 |
| `ddd` | 46374 | Fri | ddd = 영어 요일 줄임 |
| `yyyy"년" m"월" d"일"` | 46360 | 2026년 12월 4일 | 한글 날짜 · m d 하나는 앞 0 없음 |
| `yyyy-mm-dd` | 46360 | 2026-12-04 | mm dd 는 앞 0 |
| `0세` | 45 | 45세 | 따옴표 없이 세 |
| `#,##0원` | 30000 | 30,000원 | 따옴표 없이 원 |
| `000` | 45 | 045 | 0 의 개수만큼 자리(앞 0) |
| `0` | 12.5 | 13 | 소수가 반올림돼 보임(값은 12.5) |
| `@"님"` | 가람 | 가람님 | 글자 뒤에 붙이기 @ |
| `#,##0;-#,##0;` | 0 |  | 0 구역을 비우면 0 이 안 보임 |
| `#,##0;(#,##0)` | -450 | (450) | 음수를 괄호로 |
| `0"세"` | ="34세"+1 | #VALUE! | 글자 '34세'에 더하기 |
| `#,##0;[빨간색]-#,##0` | -450 | 넣지 못함 | 색 이름 [빨간색](MS 도움말 예시의 이름) |
| `[파랑]#,##0;[빨강]-#,##0` | 1120 | 1,120 | 양수 파랑 |

구역 순서(양수;음수;0;글자) · 끝 쉼표 1,000 단위 · 글자 큰따옴표 · @ 는 Microsoft 도움말 「숫자 서식을 사용자 지정하는 지침」(https://support.microsoft.com/ko-kr/excel/review-guidelines-for-customizing-a-number-format) 의 규칙. aaa · aaaa(한국어 요일)와 색 이름([빨강] 받음 · [Red] · [빨간색] 거부)은 이 PC 한국어 엑셀에서 잰 것.
