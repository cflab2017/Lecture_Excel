## 문제

**31. (기본)** '분석작업-31' 시트 — [표31]에서 부분합 기능을 이용하여 '지점'별 '판매액'의 합계를 계산하시오. ▶ 정렬은 '지점'을 기준으로 오름차순으로 처리하시오.

**32. (응용)** '분석작업-32' 시트 — [표32]에서 부분합 기능을 이용하여 '부서'별 '기본급'의 최대값을 계산한 후 '수당'의 평균을 계산하시오. ▶ 정렬은 '부서'를 기준으로 내림차순으로 처리하시오. ▶ 최대값과 평균은 위에 표시된 순서대로 처리하시오.

**33. (함정)** '분석작업-33' 시트 — [표33]에서 부분합 기능을 이용하여 '직위'별 '이름'의 개수를 계산하시오. ▶ 정렬은 '직위'를 '부장, 과장, 대리, 사원' 순서로 처리하시오.

## 풀이 · 실측 값

데이터 → 정렬 → 데이터 → 부분합(데이터 아래에 요약 표시).

| 문제 | 정렬 | 부분합 | 결과(요약 줄) |
|---|---|---|---|
| 31 | 지점 오름차순 → 대구 · 부산 · 서울 | 지점 · 합계 · 판매액 | 대구 요약 600,000 · 부산 요약 800,000 · 서울 요약 1,330,000 · 총합계 2,730,000 (A2:D16) |
| 32 | 부서 내림차순 → 총무부 · 영업부 · 기획부 | ① 부서 · 최대값 · 기본급 → ② 부서 · 평균 · 수당, **새로운 값으로 대치 해제** | 부서마다 **평균 줄이 위, 최대 줄이 아래**(총무부 평균 123,333 / 총무부 최대 3,300,000 …) · 맨 아래 전체 평균 149,000 · 전체 최대값 3,600,000 (A2:D20) |
| 33 | 직위 — 사용자 지정 목록 부장, 과장, 대리, 사원 | 직위 · 개수 · 이름 | 부장 개수 2 · 과장 개수 2 · 대리 개수 3 · 사원 개수 3 · 전체 개수 10 (A2:D17) |

요약 칸은 `=SUBTOTAL(9,D3:D5)`(합계) · `=SUBTOTAL(4,…)`(최대) · `=SUBTOTAL(1,…)`(평균) · `=SUBTOTAL(3,…)`(개수) 수식이다. 부서별 줄 이름은 '총무부 최대'인데 맨 아래는 '전체 최대값'으로 나왔다.

## 자주 틀리는 것 (같은 자리에서 잼)

| 한 것 | 결과 |
|---|---|
| 31: 정렬하지 않고 바로 부분합 | 같은 지점이 떨어져 있어 줄마다 요약 — 요약 10줄 + 총합계(A2:D23). 총합계는 2,730,000 으로 같음 |
| 31: 부분합 → 모두 제거 | 요약 줄이 빠지고 정렬된 10줄(A2:D12)로 돌아옴(정렬은 그대로) |
| 32: 두 번째 부분합에서 '새로운 값으로 대치'를 그대로 둠 | 최대 줄이 사라지고 평균 줄만(A2:D16) |
| 32: 평균을 먼저, 최대값을 나중에 | 부서마다 최대 줄이 위, 평균 줄이 아래 · 맨 아래 전체 최대값 → 전체 평균 — 문제의 순서와 반대 |
| 33: 직위를 그냥 오름차순 | 과장 · 대리 · 부장 · 사원(가나다) 순 |
