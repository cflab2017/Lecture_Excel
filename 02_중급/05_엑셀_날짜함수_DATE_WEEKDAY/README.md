엑셀은 따로 띄워 **숨긴 채** 쓴다(창 · 키 입력 · 클립보드 · 화면 캡처 안 씀). 확인 환경: 엑셀 Microsoft 365(버전 16.0), 2026-11-18.
'오늘'은 TODAY() 대신 **기준일 칸(G3 = 2026-12-31)** 으로 둔다 — TODAY 는 여는 날마다 값이 바뀌어 실측 값을 적어 둘 수 없다.

## 문제

**13. (기본)** [표13]에서 입사일[B3:B10]을 이용하여 입사 연도[C3:C10]와 입사 월[D3:D10]을 표시하고, 기준일[G3]의 연도에서 입사 연도를 빼서 근속 연수[E3:E10]를 구하시오. ▶ YEAR, MONTH 함수 사용

**14. (응용)** [표14]에서 년[B14:B21] · 월[C14:C21] · 일[D14:D21]을 이용하여 날짜[E14:E21]를 구하고, 그 날짜의 요일을 '월'~'일'로 요일[F14:F21]에 표시하시오. (단, 요일은 월요일이 1 인 유형 사용) ▶ ① DATE 함수 ② CHOOSE, WEEKDAY 함수 사용

**15. (함정)** [표15]에서 체크아웃[C25:C32]에서 체크인[B25:B32]을 빼서 숙박 일수[D25:D32]를 숫자로 구하고, 체크인이 토요일 또는 일요일이면 '주말', 아니면 '평일'을 요금 구분[E25:E32]에 표시하시오. ▶ ① 날짜 빼기(숫자로 표시) ② IF, WEEKDAY 함수 사용

## 풀이 순서

| 문제 | 누르는 칸 | 넣는 수식(그대로) | 그다음 |
|---|---|---|---|
| 13 | C3 | `=YEAR(B3)` | Enter → C3:C10 고르고 Ctrl+D |
| 13 | D3 | `=MONTH(B3)` | Enter → D3:D10 고르고 Ctrl+D |
| 13 | E3 | `=YEAR($G$3)-YEAR(B3)` | Enter → E3:E10 고르고 Ctrl+D |
| 14 ① | E14 | `=DATE(B14,C14,D14)` | Enter → E14:E21 고르고 Ctrl+D |
| 14 ② | F14 | `=CHOOSE(WEEKDAY(E14,2),"월","화","수","목","금","토","일")` | Enter → F14:F21 고르고 Ctrl+D |
| 15 ① | D25 | `=C25-B25` | Enter → D25:D32 고르고 Ctrl+D → 날짜로 보이면 표시 형식 '일반' |
| 15 ② | E25 | `=IF(WEEKDAY(B25,2)>=6,"주말","평일")` | Enter → E25:E32 고르고 Ctrl+D |

WEEKDAY 유형: 생략(1) = 일요일 1 … 토요일 7 · 2 = 월요일 1 … 일요일 7 · 3 = 월요일 0 … 일요일 6.

## 한 칸 사실(일반 칸에 넣어 잼)

| 식 | 결과 | 뜻 |
|---|---|---|
| `=DATE(2026,13,1)` | 2027-01-01 | 13월 → 다음 해 1월 |
| `=DATE(2026,2,30)` | 2026-03-02 | 2월 30일 → 3월로 넘어감 |
| `=DATE(26,5,5)` | 1926-05-05 | 두 자리 연도 26 |
| `=DATE(2026,3,0)` | 2026-02-28 | 0일 = 앞 달 마지막 날 |
| `=DAY(DATE(2026,3,0))` | 28 | 그 달이 며칠까지인지 |
| `=WEEKDAY(DATE(2026,11,18))` | 4 | 유형 생략(일=1) |
| `=WEEKDAY(DATE(2026,11,18),2)` | 3 | 유형 2(월=1) |
| `=WEEKDAY(DATE(2026,11,18),3)` | 2 | 유형 3(월=0) |
| `=YEAR(0)` | 1900 | 빈 칸 · 0 의 연도 |
| `=MONTH(0)` | 1 | 빈 칸 · 0 의 월 |
| `=DAY(0)` | 0 | 빈 칸 · 0 의 일 |
| `=YEAR("2026-11-18")` | 2026 | 글자 날짜도 읽음 |
