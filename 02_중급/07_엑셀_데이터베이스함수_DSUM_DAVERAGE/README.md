## 문제

**19. (기본)** [표19]에서 지점이 '서울'인 판매의 금액 합계를 [H3]에, 판매 건수를 [I3]에 표시하시오. (조건은 [G2:G3] 영역 사용, 판매 건수는 수량 필드로 셈) ▶ DSUM, DCOUNT 함수 사용

**20. (응용)** [표20]에서 성별이 '여'이고 나이가 30 이상인 회원의 기록(분) 평균을 반올림하여 소수 첫째 자리까지 [I14]에, 종목이 '수영' 또는 '요가'인 회원의 가장 긴 기록(분)을 [I17]에 표시하시오. (조건은 [G13:H14] · [G16:G18] 영역 사용) ▶ ① ROUND, DAVERAGE 함수 ② DMAX 함수 사용

**21. (함정)** [표21]에서 분류가 정확히 '문구'인 상품(문구류는 제외)의 최소 재고를 [G25]에, 재고 합계를 [H25]에 표시하시오. (조건은 [F24:F25] 영역에 입력하여 사용) ▶ DMIN, DSUM 함수 사용

## 한 칸 사실

| 식 | 결과 | 뜻 |
|---|---|---|
| `=DSUM(A2:E10,"금액",G2:G3)` | 373000 | 필드 번호 대신 머리글 이름 |
| `=DCOUNTA(A2:E10,1,G2:G3)` | 4 | DCOUNTA 는 글자 칸도 셈 |
| `=DCOUNT(A2:E10,,G2:G3)` | 4 | 필드를 비우면 조건에 맞는 줄 수 |
| `=SUMIF(A3:A10,"서울",E3:E10)` | 373000 | SUMIF 로 같은 합계 |
| `=DAVERAGE(A13:E21,"기록(분)",G13:H14)` | 48.5 | ROUND 없이 평균 |
| `=DMIN(A13:E21,5,G16:G18)` | 35 | 수영 · 요가 최단 |
| `=COUNTIFS(B14:B21,"여",C14:C21,">=30")` | 4 | COUNTIFS 로 여 · 30 이상 사람 수 |
