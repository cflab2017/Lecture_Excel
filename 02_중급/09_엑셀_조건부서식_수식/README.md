## 문제

**25. (기본)** [표25]의 [A3:D10] 영역에서 결석이 3 이상인 행 전체에 글꼴 스타일 '굵게', 글꼴 색 '표준 색-빨강'을 적용하시오. (규칙 유형은 '수식을 사용하여 서식을 지정할 셀 결정', 한 개의 규칙으로)

**26. (응용)** [표26]의 [A14:C21] 영역에서 분류가 '음료'이면서 재고가 10 미만인 행 전체에 채우기 색 '표준 색-노랑'을 적용하시오. (AND 함수 사용)

**27. (함정)** [표27]의 [A25:C32] 영역에서 실적이 실적 전체의 평균 이상인 행 전체에 글꼴 스타일 '굵게', 글꼴 색 '표준 색-파랑'을 적용하시오. (AVERAGE 함수 사용)

## 풀이 · 실측 값

범위를 머리글 빼고 위에서부터 고른 뒤 홈 → 조건부 서식 → 새 규칙 → '수식을 사용하여 서식을 지정할 셀 결정' → 수식 → 서식 → 확인.

| 문제 | 범위 | 수식 | 칠해진 행 |
|---|---|---|---|
| 25 | A3:D10 | `=$D3>=3` | 4 · 6 · 8 · 9행(누리 · 라희 · 비주 · 세찬) — A~D 모두 굵은 빨강 |
| 26 | A14:C21 | `=AND($B14="음료",$C14<10)` | 14 · 17 · 20행(생수 · 주스 · 우유) — 노랑 |
| 27 | A25:C32 | `=$C25>=AVERAGE($C$25:$C$32)` | 26 · 28 · 30 · 32행(김솔 · 도현 · 문결 · 서율) — 굵은 파랑, 평균 1,091.875 |

## 자주 틀리는 규칙 (같은 범위에 넣어 잼)

| 규칙 | 결과 |
|---|---|
| A3:D10 `=D3>=3` | A4 · A6 · A8 · A9 칸만(열도 움직임) |
| A3:D10 `=$D$3>=3` | 아무 칸도 안 칠해짐(모두 D3=1 만 봄) |
| D3:D10 만 고르고 `=$D3>=3` | D4 · D6 · D8 · D9 칸만 |
| A3:D10 '셀 값 >= 3' 규칙 | 24칸(이름 8칸 모두 — 글자는 숫자보다 큰 값으로 비교됨 · 학년 3 · 4 · 출석 전부 · 결석 4칸) |
| A2:D10(머리글부터) `=$D3>=3` | 3 · 5 · 7 · 8행 — 한 행씩 밀림 |
| A14:C21 `=OR($B14="음료",$C14<10)` | 일곱 행(과자만 빠짐) |
| A14:C21 `=AND($B14=음료,$C14<10)` | 아무 행도 안 칠해짐(규칙은 저장됨 · 오류 창 없음) |
| A14:C21 `=AND(B14="음료",C14<10)` | A14 · A17 · A20 칸만 |
| A14:C21 `=AND($B14="음료",$C14<=10)` | 네 행(재고 10 인 커피까지) |
| A25:C32 `=$C25>=AVERAGE(C25:C32)` | A26 · A28 · A32 칸만 |
| A24:C32(머리글부터) 정답 수식 | 25 · 27 · 29 · 31행 — 한 행씩 밀림 |
| A25:C32 `=$C25>AVERAGE($C$25:$C$32)` | 정답과 같음(평균과 같은 값이 없음) |

값을 바꾸면 바로 따라 바뀐다 — 정답 규칙에서 D5 를 0 → 3 으로 바꾸자 5행도 칠해짐(4 · 5 · 6 · 8 · 9행). 파일 작성자 · 마지막 저장자는 CODINGNOW.
