- 앞 강의: [중급 11강 정렬 · 부분합](../11_엑셀_정렬_부분합/) (문제 번호는 이어서 34~36)

## 파일

| 파일 | 내용 |
|---|---|
| `실습.xlsx` | `문제` 시트(문제 문장 3개) + `분석작업-34` · `35` · `36` 시트(표 A2:D12) |
| `정답.xlsx` | 같은 시트 A15 에 피벗 테이블까지 만든 것 |
| `make_measure.py` → `measure.json` | 두 파일을 만들고, 이 PC 엑셀에서 피벗 테이블을 만들어 보고서 칸의 글자를 그대로 읽고, 자주 틀리는 것을 같은 자리에서 잰다 |
| `shots/` | (저장소에는 올리지 않음) 범위를 PDF 로 내보낸 그림 |

엑셀은 따로 띄워 **숨긴 채** 쓴다(창 · 키 입력 · 클립보드 · 화면 캡처 안 씀). 그래서 '피벗 테이블 만들기' · 필드 목록 화면은 없다.
피벗 테이블은 **코드로** 만들었다(PivotCaches.Create · CreatePivotTable · 필드 Orientation · AddDataField) — 화면에서 필드를 끌어 넣을 때와 다를 수 있는 곳은 따로 적었다.
확인 환경: 엑셀 Microsoft 365(버전 16.0 빌드 20625), 2026-11-25.

## 문제

**34. (기본)** '분석작업-34' 시트 — [표34]를 이용하여 '지점'은 행, '제품'은 열로 처리하고, 값에 '판매액'의 합계를 계산하는 피벗 테이블을 작성하시오. ▶ 피벗 테이블 보고서는 동일 시트의 A15 셀에서 시작하시오. ▶ 값 영역의 숫자는 1000 단위 구분 기호(,)를 표시하시오.

**35. (응용)** '분석작업-35' 시트 — [표35]를 이용하여 '직위'는 행, '부서'는 열로 처리하고, 값에 '기본급'의 평균을 계산하는 피벗 테이블을 작성하시오. ▶ 피벗 테이블 보고서는 동일 시트의 A15 셀에서 시작하시오. ▶ 보고서 레이아웃은 개요 형식으로 표시하시오. ▶ 빈 셀은 '*' 기호로 표시하시오. ▶ 값 영역의 숫자는 1000 단위 구분 기호(,)를 표시하시오.

**36. (함정)** '분석작업-36' 시트 — [표36]을 이용하여 '판매일'은 행으로 처리하고 '월' 단위로 그룹을 지정하시오. 값에는 '수량'의 합계를 계산하는 피벗 테이블을 작성하시오. ▶ 피벗 테이블 보고서는 동일 시트의 A15 셀에서 시작하시오. ▶ 수량을 아직 못 적은 줄(D7 '미정')은 고치지 말고 그대로 두시오.

## 풀이 · 실측 값

| 문제 | 필드 | 결과(A15 부터) |
|---|---|---|
| 34 | 행 지점 · 열 제품 · 값 합계 : 판매액(#,##0) | A15:E20 · 행은 광주 · 대전 · 인천, 열은 마우스 · 모니터 · 키보드(가나다) · 인천 모니터 595,000(두 줄 합) · 총합계 1,548,000 · 압축 형식이라 머리글은 '행 레이블' · '열 레이블' |
| 35 | 행 직위 · 열 부서 · 값 평균 : 기본급(#,##0) · 개요 형식 · 빈 셀 * | A15:E20 · 머리글이 '직위' · '부서'로 바뀜 · 대리 × 총무부 = `*` · 과장 평균 3,800,000 · 대리 3,150,000 · 사원 2,790,000 · 전체 평균 3,165,000 |
| 36 | 행 판매일(월 그룹) · 값 합계 : 수량 | A15:B19 · 9월 50 · 10월 39 · 11월 86 · 총합계 175 — 수량 열에 글자 '미정'이 있어 엑셀은 처음에 **개수 : 수량**을 골랐고, '합계'로 바꿔야 함 |

값 필드 이름은 '합계 : 판매액' · '평균 : 기본급'처럼 엑셀이 붙였다(코드에서 이름을 주지 않음). 스타일은 PivotStyleLight16.

## 자주 틀리는 것 (같은 자리에서 잼)

| 한 것 | 결과 |
|---|---|
| 34: 원본 D3 을 320,000 → 420,000 으로 고침 | 새로 고침 전 피벗은 그대로 595,000 · 총합계 1,548,000 → **새로 고침** 뒤 695,000 · 1,648,000 |
| 34: 원본 13행에 한 줄 더하고 새로 고침만 | 그대로(원본 범위가 A2:D12 로 고정) → **데이터 원본 변경**(A2:D13) 뒤 광주 모니터 410,000 · 총합계 1,648,000 |
| 34: 머리글 C2(제품)를 비우고 만듦(코드) | 만들어지기는 하는데 그 필드 이름이 '필드3' — '제품'으로 고를 수 없음 |
| 34: 지점을 열, 제품을 행으로 | 표가 뒤집힘(행 마우스 · 모니터 · 키보드) — 총합계 1,548,000 은 같음 |
| 35: 레이아웃 · 빈 셀을 그대로 | 압축 형식 — 머리글이 '행 레이블' · '열 레이블', 대리 × 총무부는 빈칸 |
| 35: 테이블 형식 | 이 표(행 필드 하나)에서는 개요 형식과 글자가 같음 |
| 35: 평균으로 안 바꿈 | 합계 : 기본급 — 사원 × 영업부 5,600,000 처럼 두 사람 합 |
| 36: 함수를 고르지 않음 | **개수 : 수량** 3 · 3 · 4 · 총합계 10('미정'도 셈) |
| 36: '미정'을 지워 빈칸으로 / 0 으로 | 둘 다 엑셀이 '합계'를 고름(빈칸만으로는 개수가 되지 않음 — 코드로 넣었을 때) |
