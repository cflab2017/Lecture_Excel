# 중급 10강 — 엑셀 고급 필터, 조건 범위 AND · OR (컴활 2급 실기 기본작업 유형 연습)

## 파일

| 파일 | 내용 |
|---|---|
| `실습.xlsx` | `문제` 시트(문제 문장 3개) + `기본작업-28` · `29` · `30` 시트(표 A2:D12, 조건 · 결과 자리 비어 있음) |
| `정답.xlsx` | 조건(A14 부터)을 넣고 고급 필터(다른 장소에 복사) 결과(A18 부터)를 둔 것 |
| `make_measure.py` → `measure.json` | 두 파일을 만들고, 이 PC 엑셀에서 고급 필터를 실행해 결과 자리에 복사된 행을 읽고, 자주 틀리는 조건 11개를 같은 자리에서 잰다 |
| `shots/` | (저장소에는 올리지 않음) 범위를 PDF 로 내보낸 그림 |

엑셀은 따로 띄워 **숨긴 채** 쓴다(창 · 키 입력 · 클립보드 · 화면 캡처 안 씀). 그래서 '고급 필터' 대화 상자 화면은 없다. 확인 환경: 엑셀 Microsoft 365(버전 16.0), 2026-11-24.

## 문제

**28. (기본)** '기본작업-28' 시트 — [표28]에서 부서가 '영업부'이고 점수가 80 이상인 데이터를 고급 필터를 사용하여 검색하시오. 조건은 [A14:B15] 범위 내에 알맞게 입력하고, 결과는 [A18] 셀부터 표시하시오.

**29. (응용)** '기본작업-29' 시트 — [표29]에서 분류가 '소설'이거나 대출 횟수가 20 이상인 데이터의 '도서명', '대출 횟수' 필드만 고급 필터를 사용하여 검색하시오. 조건은 [A14:B16] 범위 내에 알맞게 입력하고, 결과는 [A18] 셀부터 표시하시오.

**30. (함정)** '기본작업-30' 시트 — [표30]에서 품목이 정확히 '노트'이고 재고가 100 미만인 데이터를 고급 필터를 사용하여 검색하시오. 조건은 [A14:B15] 범위 내에 알맞게 입력하고, 결과는 [A18] 셀부터 표시하시오. ('노트'로 시작하는 다른 품목은 나오면 안 됨)

## 풀이 · 실측 값

데이터 → 정렬 및 필터 → 고급 → 다른 장소에 복사.

| 문제 | 조건 범위 | 복사 위치 | 결과 |
|---|---|---|---|
| 28 | A14:B15 — 부서 · 점수 / 영업부 · >=80 (같은 줄) | A18 | 가람 86 · 마루 80 · 여름 91 |
| 29 | A14:B16 — 분류 · 대출 횟수 / 소설 / (다음 줄) >=20 | A18:B18(도서명 · 대출 횟수를 먼저 적음) | 별빛 정원 · 숫자의 힘 · 바람의 노래 · 여행 노트 · 푸른 밤 · 데이터 읽기 (두 필드만) |
| 30 | A14:B15 — 품목 · 재고 / `="=노트"`(칸에는 =노트) · <100 | A18 | 노트(재고 45) |

## 자주 틀리는 조건 (같은 자리에서 잼)

| 조건 | 결과 |
|---|---|
| 28: 점수 조건을 한 줄 내림(A14:B16) | 9명 — '또는'(윤슬만 빠짐) |
| 28: `>80` | 가람 · 여름(마루 80 빠짐) |
| 28: 정답 조건 + 빈 셋째 줄까지 범위(A14:B16) | 10명 전부 |
| 28: 조건 머리글 '점수 '(끝 공백) | 0명 |
| 28: `80`(부등호 없음) | 마루 1명(같은 값) |
| 29: 소설 · >=20 같은 줄 | 바람의 노래 1권 |
| 29: 복사 위치 A18 한 칸 | 6권 · 네 필드 모두 |
